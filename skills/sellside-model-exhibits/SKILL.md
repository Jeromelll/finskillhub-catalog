# 测算表与敏感性矩阵

表格让读者看懂输入如何得到结果，并找到关键假设、来源与边界。先核对模型，再排版。

## 选择表格

- 计算桥：输入 → 中间量 → 收入 → 利润 → EPS，每一步用 ×、＋、÷、＝ 标示。对标数据放相邻备注行，避免混入公式。
- 情景表：左侧统一行定义，中间并列完整情景，右侧 Comment 解释来源、假设与成本边界。情景数量按问题选择。
- 敏感性矩阵：两轴各一个独立输入，表头写变量和单位，标题写输出指标、单位与年份。多个输出使用同一模型。

制作时读 [表格设计规范](references/table-design.md)，调用脚本时读 [结果接口](references/render_schema.md)。

## 保留数字含义

1. 只读取计算结果，不为贴近某张图而手填结果或消除差异。缺失值显示 -，说明或诊断解释原因。
2. 阅读表用蓝字标假设、黑字标计算、浅黄和粗体标关键结果。预测与已实现事实通过标签和来源明确区分。
3. Excel 基准／实际输入为蓝色，预测硬填为红色，公式为黑色。reported 保留来源值；缺少利润桥时不补造公式。
4. 缩进表示组成关系，分块横线表示计算阶段。标签左对齐，数值右对齐，小数位按单位统一。
5. 每张表带对象、期间、单位、固定假设和来源定位；EPS 金额与 EPS 上行百分比分别标注。

## 生成与检查

依赖 Python、Pillow、openpyxl 和可显示所需字符的系统字体：

```sh
python3 scripts/render_exhibits.py --input results.json --outdir output
```

同一份结果生成 HTML、PNG、Excel、审计 XML（exhibits.xml）及可导入飞书的正文片段（feishu.xml）。正文片段含原生表格、来源和人读脚注；机器诊断留在审计输出。Excel 公式绑定到对应场景输入行，并设置打开时自动重算；生成器本身不运行 Excel 重算引擎。

必要复核：关键数字一致，表头、单位和固定假设齐全，公式没有跨场景串列，缺失值没有变零，中文和长备注没有截断。文档导入仍应使用目标平台的正式接口并读回核验。

随包仅提供通用金融表格结构，不含机构标识、商业研报原件、报告截图或从报告复算的模型样例。使用另一项技能提供的原创合成示例可在离线环境验证输入输出。
