# 表格与图形样式

输出以一张可复核的测算桥和独立敏感性表为主，不做 dashboard。HTML 适合阅读和复制；`feishu.xml` 是可直接由 `docs +update --content` 导入的飞书表格片段；`exhibits.xml` 保留原始值和诊断供审计；XLSX 保留输入、公式、来源批注和审计表；PNG 作为静态图表插入文档。

## 读者视线

测算桥按输入文件中的行顺序展示，调用方应按“容量和价格假设 → 收入 → 增量利润 → 税后 EPS”的因果顺序排序。`section` 行使用浅灰底和分隔线；`key: true` 的关键结果使用浅黄底，标签和数值加粗。数值右对齐，文字左对齐，单位独立显示，缩进由 `indent` 控制，并映射为真实左内边距。Comment 列紧邻情景列，合并呈现 `comment` 与 `evidence` 并允许长文本换行。横向情景按 A/B/C 或年份并排，不将不同单位的数值挤到同一列。

假设用少量蓝色字强调，计算结果用黑色，关键结果再配浅黄底。未知、缺失和阻断值统一显示 ASCII `-`。`section`、`note` 等文字行不承担数值运算。来源要带机构、标题或原文定位；若输入提供页码，图注、XML 和审计信息保留该页码。图注同时标明期间、货币和数据口径。

## 单位和格式

`unit` 与输入值同口径展示，不进行数值缩放。例如 `2,000` 的 `USD_mn` 原值仍是 2,000，不能改成 2.000 或按图表来源改写结果。读者界面将常用单位代码映射为“百万美元”“十亿美元”“百万人”“%”等清楚标签；也可用 `unit_label` 显式覆盖标签。若要改变数值尺度，上游必须显式提供换算后的行和可复核公式。敏感性轴可提供 `format`（如 `percent:1`），比例值 0.6 显示为 60.0%；敏感性输出单位显示在标题副题或图注，不额外占用空白数据列。

百分比输入使用小数比例，例如 `0.126` 显示 `12.6%`。货币和 EPS 数值使用顶层 `currency` 的符号，读者表的单位列用中文或明确的常用单位，`Audit` 仍保留 `USD_mn`、`USD/share` 等机器口径。不同材料的年度和单位不同，应在情景标签、行单位、轴标题或脚注中显式写出，不能靠颜色暗示。

## Excel 约定

`Bridge` 表是一张读者表。预测硬填的输入和原文报告值为红色；`benchmark` 基准/实际值为蓝色；公式和没有公式表达式的计算快照为黑色。快照的单元格批注会说明没有可用表达式，避免被误读为公式。`reported` 行保持原值，并在批注里标明“保留原报告值，未重算”。

`Sensitivities` 表按矩阵原样呈现输入，轴名、轴单位、结果单位、固定假设和脚注都保留。`Audit` 表按行和情景记录 row ID、标签、role、单位、格式、原始值、状态、表达式、证据、批注和对应桥单元格；完整诊断也写入 `Audit` 与 `Sources`。缺失值在读者表显示 `-`；审计表同样以 `-` 表示，不默认为 0。

表达式只能引用同一情景列的行 ID，防止跨情景混用。只有状态为 `computed`、有数值且所有引用值存在时才写入 Excel 公式；缺少依赖的计算行保留输入快照并输出诊断。工作簿设置打开时自动重算，但生成器不运行 Excel，也不声称已由 Excel 计算缓存值。

## PNG 细节

PNG 使用白底、清楚的浅灰表头与横线，重点结果用淡黄底。桥图包含相邻 Comment 列，缩进显示为实际左内边距，关键行标签和数值加粗。敏感性图用深蓝表头与白色数值区，不用渐变色；只显示一个行轴列和各列轴数值；结果单位放在副题／图注中。每张 PNG 包含标题、期间、币种、轴含义或测算桥单位，并在表格下方放来源和必要的人读脚注；机器诊断不进入 PNG。中文字体优先 PingFang，其次 Heiti、Arial Unicode；找不到本机字体时回退默认字体。图形只使用系统字体和表格线，不嵌入银行 logo。

PNG 用于文档展示，不替代原始数值表。最终对外材料仍需由上游核验假设、公式、原报告页码和文件哈希；图像清晰或公式成功生成不等于来源已验证。

## XML 交付边界

`feishu.xml` 只包含飞书支持的标题、段落、表格、列定义和加粗标签，作为正文片段导入；包含 Comment、单位、固定假设、读者脚注和来源，不包含机器诊断。`exhibits.xml` 是带根节点的审计 XML，保留原始数值、状态、来源和完整诊断，不能直接导入飞书正文。两种 XML 的用途不可互换。
