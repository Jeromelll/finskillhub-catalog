# FinSkillHub 公开技能目录

FinSkillHub 是免费的金融投研技能目录，并提供三项原创 MIT 许可研究技能。目录说明技能用途、依赖和边界，并链接来源。收录表示来源与许可证已经核对，不代表已在所有宿主环境中验证运行，也不代表投资结论经过认证。

## 浏览

- [目录与来源记录](docs/CATALOG.md)
- [结构化目录数据](data/catalog.json)
- [贡献指南](CONTRIBUTING.md)
- [原创技能](skills/)

目录、来源链接及本仓库发布的三项 MIT 技能均免费。本仓库根目录 MIT 许可适用于目录策展和原创文档；每项技能随附的 MIT 许可适用于对应技能包。未来可能单独开发完整且经过验证的研究工作流；本仓库不包含或销售付费工作流。目录条目与预览不代表其可购买、已验证或包含支持。

安装时将所需技能的完整文件夹放入宿主支持的自定义技能目录，并保留 `SKILL.md`、参考资料、脚本、示例、代理配置和 `LICENSE`。按宿主说明操作；Python 依赖需自行管理。使用前请检查文件，并在自己的环境中核验资料、假设、计算和结果。

技能不会自动抓取资料或授权交易，也不保证投资结果。
